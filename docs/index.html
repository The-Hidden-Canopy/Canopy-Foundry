Native training runtime

Neural Foundry makes training infrastructure inspectable.

Neural Foundry is the native C++ runtime for the Hidden Canopy AI stack. It provides a reusable trainer library, a full CUDA target, and explicit AMD OpenCL and CPU smoke targets for hardware-aware research runs.

Explicit boundaries

The runtime owns native training capability: request validation, backend kernels, optimizer execution, checkpoints where supported, and structured progress output. It does not own HTTP APIs, authentication, organization or role handling, audit or promotion logic, dashboards, datasets, model weights, or Python orchestration. Those concerns remain in the governed external wrapper and control plane.

That separation keeps hardware optimizations measurable and keeps a training artifact from becoming an automatic production decision.
